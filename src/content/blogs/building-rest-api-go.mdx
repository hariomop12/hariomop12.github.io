## Introduction

Go has become one of the best choices for building high-performance REST APIs. Its simplicity, built-in concurrency, and excellent standard library make it a joy to work with.

## Setting Up the Project

First, let's initialize our Go module:

```bash
mkdir go-api && cd go-api
go mod init github.com/yourname/go-api
```

## Building the Server

Here's a simple HTTP server with routing:

```go
package main

import (
    "encoding/json"
    "log"
    "net/http"
)

type Response struct {
    Message string `json:"message"`
    Status  int    `json:"status"`
}

func homeHandler(w http.ResponseWriter, r *http.Request) {
    if r.URL.Path != "/" {
        http.NotFound(w, r)
        return
    }
    
    json.NewEncoder(w).Encode(Response{
        Message: "Welcome to the API",
        Status:  200,
    })
}

func main() {
    http.HandleFunc("/", homeHandler)
    log.Println("Server starting on :8080")
    log.Fatal(http.ListenAndServe(":8080", nil))
}
```

> **Pro Tip**: Always use environment variables for configuration in production. The `os.Getenv()` function is your friend.

## Adding Middleware

Middleware in Go is beautifully simple:

```go
func loggingMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        log.Printf("%s %s", r.Method, r.URL.Path)
        next.ServeHTTP(w, r)
    })
}

func authMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        token := r.Header.Get("Authorization")
        if token == "" {
            http.Error(w, "Unauthorized", http.StatusUnauthorized)
            return
        }
        next.ServeHTTP(w, r)
    })
}
```
